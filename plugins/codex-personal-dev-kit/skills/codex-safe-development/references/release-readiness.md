# 发布准备

本流程只准备可供用户审查的发布材料，不自动发布或部署。

## 检查清单

- Goal 和验收条件全部有证据。
- 相关测试、类型、lint、构建和安全检查通过。
- 数据迁移、备份和回滚已演练或明确未验证。
- 配置、环境变量、密钥和功能开关有清单。
- 依赖和锁文件变化已审查。
- 用户可见变化、兼容性和已知限制有说明。
- 监控、告警、日志和故障负责人明确。
- 版本号、变更记录和发布说明已准备但未发布。

## 交付

输出：候选提交、验证摘要、风险、回滚步骤、人工发布命令和发布后检查。项目内的正式里程碑可先通过 guarded `version` 建立本地标签；push、远程 tag/release、deploy、包发布和生产迁移仍标为“用户手动执行”。
