# 安全检查

## 输入与边界

- 验证外部输入的类型、长度、格式、路径和权限。
- 防止命令、SQL、模板、HTML 和路径注入。
- 上传文件验证内容、大小、扩展名、存储位置和访问控制。
- 服务端重新验证客户端约束，不信任隐藏字段或前端权限判断。

## 身份与权限

- 默认拒绝，按资源和动作检查授权。
- 区分认证失败与无权限，避免泄露资源存在性。
- 高风险动作使用重认证、审计日志或双重确认。
- 子代理和后台任务继承父任务权限，不授予额外密钥。

## 密钥与隐私

- 密钥来自环境或受管密钥服务，不写入源码、日志、测试快照或聊天文档。
- `.env`、凭据、数据库副本和用户导出默认加入忽略规则。
- 日志只记录诊断所需字段，脱敏 token、密码和个人数据。
- 发现疑似真实密钥时停止传播，说明轮换和清理步骤，但不自动轮换。

## 验证

- 添加负向测试和越权测试。
- 检查错误处理是否 fail closed。
- 对依赖和配置变化运行适用的安全扫描。
- 高风险改动使用独立只读审查者。
