# 子代理结果合同

要求子代理按以下结构返回，省略不适用字段：

```markdown
## Conclusion
<一句话结论>

## Evidence
- <文件、符号、命令、官方资料或复现步骤>

## Findings
- [severity] <真实问题及影响>

## Uncertainty
- <未读取、未运行或无法确认的内容>

## Changes
- <修改的文件；只读任务写 None>

## Verification
- <执行的检查和结果>

## Recommendation
<给主代理的一个明确下一步>
```

## 约束

- 不返回完整日志；只摘取决定结论所需的行。
- 不把猜测写成事实。
- 不扩大任务范围或直接实施额外建议。
- 引用本地文件时提供路径和尽可能具体的位置。
- 发现阻塞立即报告，不用无关工作填满上下文。
