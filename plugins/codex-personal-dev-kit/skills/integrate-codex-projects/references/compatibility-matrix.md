# 项目融合兼容矩阵

融合前只记录会改变方案的差异：

| 维度 | 检查内容 |
| --- | --- |
| 产品 | 用户、主流程、重复功能、保留/替代/删除行为 |
| 技术栈 | 语言、框架、运行时、平台和构建方式 |
| 数据 | 数据模型、数据库、文件格式、迁移和回滚 |
| 身份权限 | 账号、登录、角色、密钥和访问边界 |
| 接口 | 模块入口、API、事件、后台任务和错误处理 |
| 依赖 | 版本冲突、锁文件、原生组件和供应链风险 |
| UI | 设计系统、导航、状态、响应式和可访问性 |
| 许可证 | 代码归属、允许用途、署名和再分发要求 |
| 验证 | 现有测试、缺失行为测试和端到端检查 |
| 运行 | 配置、端口、进程、日志、备份和恢复 |

矩阵是当前决策工具，不是永久大文档。只保留阻断项、已选方案和需要验证的假设。
