## Rules

- Add one row only when a complete milestone is verified and ready to receive a local version tag such as `v1.2.0`.
- Describe recognizable capabilities so the user can identify a version without remembering its number.
- Keep newer rows when restoring an older product version; Git tags remain the exact recovery locators.
- Do not add commit hashes, full diffs, task logs, dates for every edit, or ordinary checkpoints.
