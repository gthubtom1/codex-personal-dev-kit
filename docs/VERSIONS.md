## 规则

- 每个正式版本必须对应干净、已验证的 Dev Kit 检查点和根目录 `VERSION`。
- 不记录聊天历史、完整 diff、压力测试日志、安装缓存或普通检查点。
- 本地标签不等于已经 push、发布或创建 GitHub Release。
