| DK-019 | Get back an edit that was just lost, without staging anything | `workspace_snapshot.py snapshot` -> throwaway `GIT_INDEX_FILE` capture of tracked and untracked work -> commit parked under `refs/codex-wip/` -> staged-fingerprint self-check -> `list` -> `restore` into an empty directory outside the working tree | A snapshot is stored as a real recoverable commit that `git status`, `git log`, `git branch` and `git stash list` never show, while the user's Git index is provably untouched: the run compares the staged fingerprint before and after and discards its own snapshot if it moved.
