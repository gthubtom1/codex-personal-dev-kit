# Roadmap

## Milestone 1: Beginner-first local baseline

- 完成单入口助手和六个内部 Skills。
- 完成母文件夹/projects 工作区和独立项目创建。
- 完成功能地图、项目文档、Agents、Rules、Hooks 和安全脚本。
- 完成静态验证、幂等性和危险命令测试。

## Milestone 2: Forward testing

- 用全新上下文测试一句话新项目。
- 测试已有功能保护、职责混杂代码、脏工作树和长任务恢复。
- 测试自适应子代理、单一写入者和 Worktree 隔离。
- 根据真实失败收紧 Skill 和用户交互。

## Milestone 3: Versioned installation

- 创建首个稳定本地 Tag。
- 从固定 Git ref 安装 Marketplace 和 Plugin。
- 在新任务中验证 Plugin、Hook 信任和全局 Profile。
- 配置真实 GitHub 仓库地址后启用固定 Release Bootstrap。
