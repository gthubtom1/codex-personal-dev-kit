# Roadmap

## Current Milestone

- Publish a clean MIT-licensed v0.2.2 GitHub checkout that can rebuild both AGENTS layers, Skills, runtime, templates and diagnostics on another Windows computer, including explicitly authorized guarded branch/tag backup.
- Keep ignored stress-test output and interpreter caches outside the distribution while retaining repeatable tests.

## Next Milestone

- Add focused regression tests for any real failure found during project use.
- Keep Skills, global instructions, and project documents concise as Codex capabilities evolve.

## Later

- Add separately tested guarded workflows for project dependency installation, stale Worktree cleanup, Git synchronization/integration, and narrow reversible index/worktree repair where real use proves they are needed.
- Configure separate private remotes for each long-term project when the user requests off-device project backup; the public Dev Kit repository does not contain project source or data.
- Preserve license and third-party notices in future formal versions and recheck attribution when external source code is ever vendored or adapted.
