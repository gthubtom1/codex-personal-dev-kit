## Navigation rules

- Keep durable facts in the smallest appropriate document and link to them from here.
- Keep tests and Git as evidence and history; do not append chat transcripts or full diffs to documentation.
- When a document moves or a new stable capability is added, update this map and the relevant Feature ID.
